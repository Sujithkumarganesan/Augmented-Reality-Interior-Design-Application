## Project Overview

The **Augmented Reality Interior Design Application** is an Android application that enables users to visualize and customize 3D furniture models in real-world environments using Augmented Reality (AR).

Built using Kotlin, Jetpack Compose, and ARCore, the application provides an interactive virtual interior design experience. Users can browse furniture models, select products, place them in their surroundings, and customize their appearance through an intuitive interface.

## Features

- Browse a collection of 3D furniture models.
- Visualize furniture in real-world environments using AR.
- Place and position furniture objects in the selected space.
- Scale and rotate 3D furniture models.
- Customize furniture appearance and colors.
- Capture and share AR interior design scenes.
- Interactive and user-friendly Android interface.

## Technology Stack

- **Programming Language:** Kotlin
- **UI Framework:** Jetpack Compose
- **Augmented Reality:** Google ARCore
- **3D Rendering:** Google Filament
- **AR Rendering Framework:** ARSceneView
- **3D Model Source:** Sketchfab API
- **Database:** Room Database
- **Architecture:** MVVM
- **Networking:** Retrofit and Kotlin Coroutines
- **Dependency Injection:** Hilt

## Application Requirements

- Android smartphone supporting Google ARCore.
- Compatible Android operating system.
- Internet connection for downloading 3D furniture models.

## Installation and Setup

1. Clone this repository:

   ```bash
   git clone https://github.com/Sujithkumarganesan/Augmented-Reality-Interior-Design-Application.git
   ```

2. Open the project using Android Studio.
3. Configure the required API credentials.
4. Sync the Gradle dependencies.
5. Connect an ARCore-supported Android device.
6. Build and run the application.

## Project Structure

The application follows the MVVM architecture to maintain separation between UI, business logic, and data management.
